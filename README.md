# school-website-PPESS-

Website for **Pawan Prakriti English Secondary School**, Tikathali, Mahalaxmi Municipality-5, Lalitpur, Nepal.

Built with Vite, React, TypeScript and Tailwind CSS.

## Run it

You need [Node.js](https://nodejs.org/) installed.

```bash
npm install      # download the libraries (first time only)
npm run dev      # open the local address it prints, e.g. http://localhost:5173
```

## Build it

```bash
npm run build          # static website in dist/ (for web hosting)
npm run build:offline  # single-file copy in dist-offline/ (opens by double-clicking index.html)
```

See [README-EDITING.md](README-EDITING.md) for how to edit the content.
